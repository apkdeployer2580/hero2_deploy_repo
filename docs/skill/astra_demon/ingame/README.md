## 게임 크기로 옮기며 조정한 부분

- 큰 콘셉트의 근육·갈기 묘사는 현재 작은 악마 도트의 식별 가능한 형태로 축약.
- 일반 참격은 캐릭터 앞에 집중하고, 접촉광은 작은 밝은 점으로 분리.
- 돌진은 기울어진 몸과 뒤쪽 잔상·불꽃으로 방향을 보여 줌.
- 추종의 반구 내부에는 캐릭터와 배경이 보이도록 함. 종료 가시는 별도 장면.
- 지옥칼날은 바닥 인장과 각 적 위치에 솟는 칼날을 분리.
- 어둠심판은 적을 향한 가는 낙뢰, 멸화는 악마 주변의 넓은 분출로 구분.
- 용암불은 바닥에 연결된 균열을 남기고, 냉각 단계에서 불꽃 수와 밝기를 낮춤.
- 하단 HUD를 가리지 않는 구도로 정리.

참고한 논리 크기는 화면 176×220, 타일 16px, 악마 시트 30×36px입니다.
프롬프트에 적은 효과 픽셀 크기는 생성 방향을 정한 목표값이며, 출력물 측정값이나 확정 구현 규격이 아닙니다.
실제 스킬 판정 범위·지속시간·SP·피해량은 변경하지 않았습니다. 특히 큰 범위 기술의 피해 칸은 이 예상도의 보이는 화염 면적과 일치한다고 해석하지 않습니다.
