# 「악마화」 HD (6차, 2026-10-15) — 이펙트 · 악마 외형을 예상도 해상도(3×)로

사용자: *"야수 스킬이 여전히 일부 이펙트가 살짝 어색한 부분이있어. 예를들어 캡쳐를 그대로 사용하니까 칼날스킬 원이 뭔가 잘린느낌이
들기도하고 기본공격시에도 뭔가 이상한 이펙트들이 주변으로 나와. 간단하게 할퀴는 이펙트와 흙먼지가 튀는 이펙트만 있으면 돼. 그리고 이제
이펙트 크기에 맞춰서 실제 맞는 영역도 조절할꺼야. 이펙트와 외형 전부 업스케일링하고 자연스럽게 변경하자"* →
*"맞는 영역은 항상 이펙트보다 넓은 범위여야해. 예를들어 앞에 1.5칸을 긁는 이펙트로 할퀴었다면 데미지가 들어가는 영역은 2칸이어야한다는거야."*

정본(기계) = `HERO2_GUEST_RE.md` §8.78. 이 폴더 = probe 캡처(`--h2-hd 3`, 창 해상도 528 × 660 = 게임 176 × 220 의 3 배)와 대조 그림.
