## 왜 차이가 났나

- **해상도 탓이 아니다.** 예상도를 게임 폭 176px로 줄여도 원본과 거의 같아 보인다(비교 시트 왼쪽 = 줄인 예상도). 호스트 이펙트 라이브러리는 RGBA 풀컬러 · 크기 무제한 · 더하기 합성을 지원한다.
- **1차는 그림을 옮기지 않고 코드로 다시 그렸다.** `demon_fx.py`의 옛 그림 함수는 게임 해상도(1×)에서 PIL 다각형을 바로 칠했다 — 가장자리가 계단이고, 모양이 전부 매끈한 도형(호 · 삼각형 · 타원)이며, 불꽃 · 연기에 질감이 없었다.
- **크기를 판정 범위에 맞췄다.** 예상도의 반구 · 인장 · 분출은 판정보다 훨씬 크다.

- **할퀴기** — 1단 X: 길게 휜 붉은 초승달 둘 + 흰 심 + 붉은 빛무리 + 붉은 테의 검은 조각 + 타격 섬광. 2단: 굵은 금빛 초승달(속도선) + 안쪽 잔호 + 땅 흙먼지 꼬리. 3단: 세 줄 금빛 땅가르기 + 식어 가는 긁힘 + 큰 흙먼지 + 튀는 돌. 6프레임 동안 어두워지지 않고 가늘어지며 사라진다. 위 · 아래는 회전, 왼쪽은 거울.

- **어둠심판** — 구체: 감아 도는 보라 띠 · 빨려 드는 알갱이 · 궤도 조각. 낙뢰: 굵은 보라 줄기 + 흰 심 + 가지 6 + 땅의 빛기둥 · 큰 빛살 · 충격 고리 · 튀는 결정 · 보라 연기.
- **멸화** — 앞쪽 불혀(위 층)와 뒤쪽 불혀(같은 순간의 `fire_scorch` = 땅 층)로 나눠 악마가 불 한가운데 보이게. 바깥으로 부채꼴로 기운 불혀 37개, 끝이 노이즈로 갈라짐, 검은 바위(아래가 달군), 연기 · 불티, 그을린 땅과 식어 가는 금.
- **용암불** — 월드 정렬 64×64 질감(5×5 보로노이 + 노이즈 왜곡): 빗각 진 현무암 판 · 넓은 열 얼룩 · 굵기가 변하는 균열(흰 → 노랑 → 주황 → 빨강) · 고인 쇳물 · 박힌 바위. 불은 4×4 변형 중 절반 칸에만, 냉각 때 판이 검붉게.
