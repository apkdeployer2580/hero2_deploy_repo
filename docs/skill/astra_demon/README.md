## 스킬별 개선 방향

### 외형·변신

기존 작은 도트의 형태를 확대하여 어깨·등·팔의 무게와 긴 갈기를 읽을 수 있게 했다.
start1의 허리 고리, start2~3의 인간 실루엣과 떠오르는 검은 조각, start4의 붉은 핵, start5의 악마 출현, start6의 착지를 순서대로 유지했다.
기존 초안의 독립된 큰 흰 원형 섬광 대신, 출현 순간 악마 윤곽을 밝히는 짧은 테두리 섬광을 중심으로 했다.
변신 전 무기·복장은 레퍼런스 설명용이며 실제 적용 시 현재 플레이어 외형을 사용한다.

### 기본공격 — 할퀴기

1. 1단: 붉은 초승달을 반대 방향으로 이어 X를 만든다. 칼날 안쪽만 밝게, 바깥은 검붉게 찢어지게 한다.
2. 2단: 몸을 낮춘 뒤 금빛 세 겹 궤적을 위로 쓸어 올린다. 끝부분의 보라색 잔광은 보조색이다.
3. 3단: 세 줄을 땅으로 꽂고 얕은 긁힌 자국, 먼지, 돌을 남긴다. 하늘에서 떨어지는 어둠심판과 혼동하지 않도록 손의 움직임에서 시작한다.

보드의 밝은 장면은 타격 정점이다. 실제 연속 재생에서는 이전 참격을 빠르게 감쇠하여 몸과 다음 동작이 보이게 한다.

### 돌진

머리·등의 붉은 기운을 몸 뒤로 길게 눕혀 진행 방향을 강조한다.
낮은 전진 자세, 서로 옅기가 다른 잔상 두 개, 발밑의 낮은 먼지, 충돌 지점의 짧은 흰빛을 분리한다.
원형 불덩이를 머리 위에 얹는 기존 표현을 길게 흘러가는 불꽃 갈기로 바꿨다.

### 추종

축적 중에는 발치의 보라 기운과 작은 입자, 100%에서는 내부가 보이는 반구를 사용한다.
종료 폭발은 검은 덩어리와 비대칭 가시를 주체로 하고, 자홍 테두리와 작은 중심 섬광을 붙인다.
보라 불기둥 참고는 잔류 기운에만 반영해 멸화와 역할이 겹치지 않게 했다.
상시 버프 구간의 입자 밀도는 그림보다 낮춰야 한다. 반구는 보호막 판정 추가를 뜻하지 않는다.

### 지옥칼날

검붉은 바닥 인장과 낮은 검은 회전 궤적을 유지한다.
204432의 형태는 결정 기둥보다는 비스듬한 보라 참격으로 읽혀, 기존 수정 기둥안을 검은 속살·자홍 날을 가진 휜 칼날로 개선했다.
각 몬스터 위치에서 칼날이 솟고 내려가는 구성이며, 보드의 긴 궤적이 새 투사체나 새 사거리를 의미하지 않는다.

### 어둠심판

구체가 응축되는 상단, 적에게 떨어지는 수직 낙뢰, 바닥의 짧은 반구 충격을 구분한다.
백색은 낙뢰 심과 충돌 순간에 집중하고, 잔재는 가는 보라색 가지로 정리한다.
토글의 반복 타격마다 대형 시전 포즈를 재생하는 의미는 아니다. 실제 적용 시 구체는 활성화 강조, 작은 낙뢰는 반복 타격으로 나눈다.

### 멸화

동심원 불덩이 대신 검은 톱니 모양 외곽, 비대칭 붉은 분출, 작은 황백색 핵, 두꺼운 검은 연기를 겹친다.
발밑에서 위로 터지는 순간 폭발로 용암불과 구별한다.
정점 이후에는 화염 크기를 줄이고 연기·불씨만 남긴다.

### 용암불

별개 모닥불을 동그랗게 나열하던 구성에서 연결된 용암 균열과 어두운 지각 조각으로 바꿨다.
사용자 지정 두 장의 낮은 주황 화염, 검은 연기, 상승 불티를 반영한다.
균열 → 용암 확장 → 국소 불꽃 유지 → 붉은 균열만 남는 냉각의 흐름이다.
5초 지속 중 후반으로 갈수록 불꽃 높이와 밝기를 낮춘다. 실제 피해 칸은 기존 판정을 유지하고 용암 연결 무늬는 그 내부에서 구성한다.

## 게임 제작 시 적용 메모

이 결과는 **1536×1024 확대 콘셉트 보드**이며 투명 스프라이트, 프레임 아틀라스, 실행 결과물이 아니다.
배경·문자·캐릭터가 합쳐진 보드이므로 단순 잘라내기나 축소로 바로 게임에 투입하지 않는다.
실제 30×36 캐릭터, 16px 타일에 맞춘 수작업 도트 정리와 방향별 프레임 제작이 다음 단계다.

| 항목 | 도트 제작 방향 |
|---|---|
| 캐릭터 가독성 | 갈기·가슴 문양은 큰 명암 덩어리로 통합. 뿔·눈·발톱의 최소 식별점 유지 |
| 상시 붉은 오라 | 보드의 영웅 이미지보다 크게 줄임. 몸통 전체를 항상 밝게 감싸지 않음 |
| 변신 | 6개 그림은 핵심 포즈. 원본처럼 인간 응축 후 악마가 나타나는 순서 유지 |
| 참격 | 주 궤적 1개 + 옅은 잔상으로 단순화. 하얀 중심을 면 전체로 넓히지 않음 |
| 바닥 효과 | 바닥 문양·용암 → 캐릭터 뒤 효과 → 캐릭터 → 앞쪽 타격광 → 잔재로 레이어 분리 |
| 반복 스킬 | 강한 활성화 정점과 작은 반복 타격을 분리. 바닥 인장은 캐릭터보다 낮은 대비 |
| 용암 패턴 | 칸 경계에서 연결 가능한 균열 변형을 준비. 안전한 섬 그림이 실제 안전지대를 뜻하지 않음 |
| 판정과 시간 | 기존 전투 규칙·지속시간·범위를 유지. 보드의 연출 면적은 판정표가 아님 |

효과가 겹치는 실제 전투에서 캐릭터·적·바닥 경계가 읽히는지 확인해야 한다.
이번 작업은 정적인 이미지와 파일 구성 검토까지 수행했으며 실제 프레임 재생·엔진 성능 검증은 하지 않았다.
