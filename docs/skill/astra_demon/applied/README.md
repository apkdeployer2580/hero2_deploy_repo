## 재현

저장소 루트에서 `python tools_re/demon_look.py draft --force`, `python tools_re/demon_fx.py build`로 생성한다. 게임 ZIP 재패킹에는 기존 `make_hero2_asset.py` 흐름을 사용한다.

`tools_re/astra_demon_capture.ps1 -Scene claw`의 Scene을 `charge`, `follow`, `blade`, `judge`, `fire`, `lava`, `baseline`으로 바꾸어 재생한다. 검증용 세이브 `target/demon_probe/bench/01035D0B`와 빌드된 `target/release/wie_probe.exe`가 필요하다. 출력과 실행 인자는 `target/astra_validation/<scene>`에 기록한다. 전체 캡처 후 `python tools_re/astra_demon_gallery.py`로 이 갤러리를 재생성한다.

작업 시작 시의 본체·생성기·FX 바이너리·게임 ZIP은 `target/astra_v3_before`에 백업했다.
