# 영웅서기2 아이템 드랍표 — 사이트 생성기

**레어·에픽·영웅 장비만 표시하는 자기 완결형 HTML 한 장**이다. 신규 장신구 6종도 최신 앱 에셋에서 읽는다.
아이템·등급·종류·레벨·옵션·드랍 몬스터를 표로 보여 주며, 검색과 각 열의 오름차순·내림차순 정렬을 제공한다.
방어구·방패는 종류 칸에 **경갑/중갑** 칩이 붙는다(`body[23]`, §8.1 게이트 — 마우스를 올리면 착용 직업; 검색 「중갑」도 걸린다, 2026-10-10).
데이터·스타일·스크립트를 모두 포함하고 외부 폰트나 라이브러리는 불러오지 않는다.

★ 2026-10-23: **인장 위 두 단계도 싣는다**(사용자) — 다섯 능력치 × 이름 없는 「인장」(+5~+10) · 「상급」(+15~+20) = 10 행(`SEAL_SHOWN`; 게임에 「최상급」은 없다),
등급·레벨 칸은 「—」, 필터 칩 **인장** 추가. 둘 중 하나라도 배치된 몬스터 드랍이 없으면 생성기가 멈춘다. 같은 날 중력의 갑주 문구 = 「인벤토리 내의 장비 1개당 …」(`GearPatch::ITEMS`).

★ 2026-10-15: **장비 종류 필터 칩**(전체 · 장신구 · 중갑 · 경갑 · 도검 · 둔기 · 대형무기(대검 · 도끼) · 단검 — 여럿 고르면 합집합, 칩에 개수) · 장비 옵션 문구 = `GearPatch::ITEMS` 의 것, 그 표에 없는 장비는 **레코드 자신의 옵션 문구**(`ch.k`)로(옵션 문구가 있는 장비가 빈칸이면 생성기가 멈춘다).

```bash
python tools_re/droptable/make_drop_site.py            # → out/hero2-drop-table/index.html
cd out/hero2-drop-table && vercel deploy --prod --yes  # (처음이면 아래 「처음 배포」)
curl -s https://<프로젝트>.vercel.app/ | cmp - index.html   # 인수 기준 — 라이브가 방금 만든 파일과 바이트로 같아야 한다
```

⛔ `out/` 은 `.gitignore` 아래다 — 페이지에 게임 데이터가 들어 있으므로 저장소(공개 원격)에 올리지 않는다.
원본은 이 폴더의 생성기와 템플릿이고, 페이지는 언제든 다시 만든다.

## 처음 배포

`out/hero2-drop-table/` 에서 `vercel link`(또는 첫 `vercel deploy`)로 프로젝트를 만들면 그 폴더에 `.vercel/project.json`
이 생긴다. **그 파일이 어느 프로젝트에 올릴지를 아는 유일한 것**이다 — 링크 없는 다른 폴더에서 `vercel deploy` 하면
오류가 아니라 **새 프로젝트가 새 주소로** 생기고 사람들이 보는 주소는 옛 페이지 그대로 남는다(hero5 README 의 교훈).
`--prod` 를 줘도 CLI 로그만으로는 프로덕션에 붙었는지 알기 어려우니 마지막 `cmp` 로 확인한다.

## 무엇을 읽나 — 손으로 옮겨 적은 수치는 없다

| 입력 | 어디서 | 근거 |
|---|---|---|
| 아이템 DB `itm/NN` (이름·등급·레벨·능력치·옵션 범위·경갑/중갑) | 앱 에셋 `hero2_ktf.zip` | `decode_hero2_items.py`, `HERO2_ITEM_DB.md` |
| 적 표 `enm/enm` + 처치 루틴 `bd.q()V` (롤 1..32767, 모드 창, 표 밖 드랍) | 앱 에셋 | `decode_drops.py`, `HERO2_GUEST_RE.md` §8.9 |
| 몬스터 출현 지역 | 맵 111장 `P/m/m/*.m.gz` 의 몬스터 구간 | 아래 「맵 형식」 |
| 상점 · 조합서 | `itm/forshop` · `itm/23` 본문 끝 8 B (결과 + 재료 셋) | 이 생성기 |
| 무기 공격력 보정 · 카드 드랍 제거 | `wie_android/src/guest_anchors.rs` (`weapon_extra`, `WEAPON_SHIFT`, `card_drop_off`) | §8.26 · §8.12 |
| 앱 버전 | `android_app/version.properties` | |

앱이 더하는 상수는 **러스트 소스에서 읽는다.** 무기 보정표가 바뀌거나, 카드 드랍 패치가 사라지거나, 지워진 모드 창
패치(`drop_window_all`)가 되살아나면 생성기가 그 이름을 대며 멈춘다 — 아무도 안 도는 빌드의 확률을 조용히 인쇄하는
것보다 그 편이 낫다.

## 맵 형식 — 몬스터 구간까지 (`bf.a([B)V` @0x129a94, 2026-09-28 역어셈블)

```
[u8 번호] [u8 n][이름 cp949] [u8 n][타일셋] [u8 n][타일셋] [u8 W] [u8 H] [그리드 H×W] [그리드 H×W]
by   [s8 n]{ [u8 k][k × 3 B] }                       ← n ≤ 0 이면 건너뛴다
bi×3 [u8 u]{ [u8][i16][i16] }  ·  f [u8 u]{ … }      ← 5 B 레코드 넷 구간
몬스터 [u8 n][n × 전역 적 인덱스]  [u8 m][m × (적 인덱스, x, y)]   ← 인덱스 > 88 은 보스 경로 bf.a(BII)V
```

생성기는 111장 전부를 이 순서로 읽고 값 범위(적 인덱스 < 102, 배치 인덱스 ∈ 목록, 좌표 ∈ 맵)가 하나라도 어긋나면 멈춘다.
시험 세이브 슬롯 2 의 숲(반란전투병 #27)이 「카디프숲 남부 반란군캠프」로, #19 의 망령의 손길 드랍처 레버넌트가
「신전지하 B구역」으로 나오는 것이 교차 확인이다.

## 자기 검사 (파일을 쓰기 전에)

* 몬스터마다 모드별 표 드랍 확률의 합 ≤ 1
* 보스(드랍 게이트 0)에게 표 드랍이 없다
* 입수처(드랍·상점·조합)가 하나도 없는 장비가 없다 — 레벨 규칙 배치의 목표(`HERO2_DROP_GAPS.md`)
* 조합서 61장의 포인터가 전부 풀리고, 조합서 이름 = 결과물 이름(띄어쓰기 무시)
* 표에서 뺀 아이템(스펠카드 · 마력구 · 재료가방)이 어느 드랍 칸에도 없다 — 있으면 페이지가 진짜 드랍을 숨긴다

## 페이지가 모델링하는 것

* **확률 = 한 마리당.** 처치마다 표를 한 번 굴리고, 노말은 칸 0·1·2, 하드코어·헬은 2·3·4 만 본다. 칸 안의 id 는 균등.
* **표 밖 드랍** — 골드 65 %(몹 레벨 × 4 + 20) · 제련석 clamp(20 + 몹 레벨 − 내 레벨, 8, 40) % · 물약 10 %(반은 포도주, 반은 포션/하이포션,
  몹 레벨 > 24 면 하이포션) · 헬 하이포션 +6 %. 스펠카드 11 % 는 이 앱에서 0 이다. 전부 몹 **개체** 레벨 `bd.n` 을 쓴다.
* **착용** — 장비 창 `cc.a(BB)V` 의 칸별 허용 타입(주무기: 버서커 양손대검·양손도끼 / 나이트 도검·둔기 / 로그 도검·단검, 보조: 나이트 방패 · 로그 단검 ·
  버서커 없음) + 경갑/중갑 게이트(§8.1). 요구 레벨이 먼저 걸린다.
* **옵션** — 무기·방어구는 `h.a(0, body[4])` 개를 범위가 있는 능력치 중에서 골라 굴리고(`aa.a([BIZZ)I` 0x10d84e), 목걸이·반지는 다섯을 전부 굴린다.
  ⚠ `HERO2_ITEM_DB.md` §1 은 `body[4]` 를 「오브·결정 슬롯 수」라 적었는데, 파서는 그것을 **랜덤 옵션 최대 개수**로 쓴다.
  줍기(`ag.a()Z`)는 팩토리를 `(타입, id, true, true)` 로 불러 옵션을 굴린다.
* **배치 없음** — 신관(#23)·신관병(#24)은 드랍표가 있지만 어느 맵의 몬스터 목록에도 없다. 이벤트로 나오는지는 확인하지 못했다
  (맵 스크립트 명령 `13` 이 부르는 컷신 표를 아직 풀지 않았다). 팬텀스타·파괴마의 등뼈는 신관만 떨군다.
